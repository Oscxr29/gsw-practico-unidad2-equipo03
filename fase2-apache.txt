=====================================================================
PREGUNTA 2: ¿Qué diferencia hay entre sites-available y sites-enabled?
=====================================================================

El directorio sites-available contiene los archivos de configuración 
de los sitios web que se pueden habilitar en Apache. Por su parte, 
sites-enabled contiene normalmente enlaces simbólicos a las 
configuraciones de los sitios que están habilitados. Esto permite 
mantener configurados varios sitios web y activar o desactivar cada 
uno sin necesidad de eliminar sus archivos de configuración. 

=====================================================================
PREGUNTA 3: ¿Qué reporta configtest? ¿Por qué es importante?
=====================================================================

Reporta "Syntax OK", lo que significa que la sintaxis de todos los
archivos de configuración de Apache es correcta. Es importante porque 
permite detectar errores de configuración antes de recargar o reiniciar 
Apache, reduciendo el riesgo de interrupciones del servicio.

=====================================================================
PREGUNTA 4: Reto — Si Apache no arrancara, ¿qué 3 pasos seguirían?
=====================================================================

Paso 1. Revisar el estado del servicio:

sudo systemctl status apache2

Permite comprobar si Apache está activo y consultar posibles mensajes 
de error.

Paso 2. Verificar la configuración:

sudo apache2ctl configtest

Permite detectar errores de sintaxis en los archivos de configuración.

Paso 3. Comprobar si el puerto 80 está ocupado:

sudo ss -tlnp | grep :80

Permite identificar si algún proceso está escuchando en el puerto 80, 
lo que podría impedir que Apache utilice ese puerto.
